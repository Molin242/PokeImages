# Carpeta de criaturas

Sube aquí las imágenes (png, jpg, webp, gif, svg). Cada imagen es una criatura.

- `gato.png` → «Gato», común
- `perro_raro.jpg` → «Perro», rara
- `dragon_de_fuego_epico.png` → «Dragon de fuego», épica
- `profe_legendario.webp` → «Profe», legendaria

También puedes usar subcarpetas: `imagenes/raro/perro.jpg`, `imagenes/legendario/profe.webp`.

Consejo: los PNG con fondo transparente quedan mucho mejor en el mapa.
