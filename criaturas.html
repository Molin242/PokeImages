¿Cómo lo subo a GitHub?
  1. Pulsa Descargar cambios y descomprime el ZIP (clic derecho → Extraer todo).
  2. En tu repositorio de GitHub (en la página principal, no dentro de ninguna carpeta): Add file → Upload files.
  3. Arrastra la carpeta imagenes que sale del ZIP y pulsa Commit changes. Se añaden las criaturas nuevas y se actualiza criaturas.json.
  4. En 1–2 minutos estarán en el juego.
